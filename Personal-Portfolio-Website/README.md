
# Personal Portfolio Website

A responsive personal portfolio website built using HTML5 and CSS3.

## About the Project

This project introduces me and showcases my academic background,
projects, and contact information.

## Sections

- About
- Education
- Projects
- Contact

## Technologies Used

- HTML5
- CSS3
- CSS Media Queries for Responsive Design

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html` to view the website in a browser.
